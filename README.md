# 🌸 Rau Câu 3D Nghệ Thuật - Landing Page

Website landing page bán hàng online cho thương hiệu rau câu 3D nghệ thuật thủ công tại Tp. HCM.

## ✨ Tính năng

- **Hero Section ấn tượng** - Hiển thị sản phẩm chủ đạo với hiệu ứng nổi động
- **Bộ sưu tập sản phẩm** - 7 sản phẩm với ảnh, mô tả và giá
- **Form đặt hàng** - Thân thiện mobile, xác thực đầy đủ
- **Giá trị nổi bật (USP)** - Thể hiện điểm khác biệt thương hiệu
- **Thư viện ảnh** - Gallery layout đẹp mắt
- **Responsive hoàn hảo** - Mobile, tablet, desktop

## 🎨 Phong cách thiết kế

- **Màu chủ đạo:**
  - Trắng sữa / trong suốt (rau câu tinh khiết)
  - Hồng phấn – tím lavender – xanh ngọc nhạt (hoa 3D)
  - Điểm nhấn vàng champagne (quà tặng cao cấp)

- **Typography:**
  - Heading: Cormorant Garamond (serif thanh lịch)
  - Body: Source Sans Pro (dễ đọc)

## 🛠️ Công nghệ

- HTML5 semantic
- CSS3 với CSS Variables, Flexbox, Grid
- Vanilla JavaScript ES6+
- Google Fonts

## 🚀 Chạy dự án

### Cách 1: Mở trực tiếp
Mở file `index.html` trong trình duyệt.

### Cách 2: Live Server (khuyến nghị)
```bash
# Với Python
python -m http.server 8000

# Với Node.js
npx serve .

# Với VS Code Live Server extension
# Right-click index.html > Open with Live Server
```
